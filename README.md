# Flowline

Endless snowboarding — carve, flow, chase the horizon.

A local, playable build of [flowline.games.bu.app](https://flowline.games.bu.app/) with upgraded rider mechanics, snow trails, cloth, and camera.

## Run

```bash
npm install
npm run dev
```

Opens at `http://localhost:8080`.

## Controls

- **A / D** — lean / carve
- **Shift** — tuck
- **Space** — pop
- **Hold** on a rail for a grind

The game lives in `public/flowline.html` (Three.js). The Vite / TanStack shell serves it as the root document.
